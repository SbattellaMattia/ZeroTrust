Nota accademica

Questo sistema dimostra i principi dell’architettura Zero Trust applicati a un controllo dinamico degli accessi. Il livello di accesso dipende dal trust score dell’utente:

  • Trust score ≥ 70: accesso completo (full)
  • 50 ≤ trust score < 70: accesso limitato
  • Trust score < 50: accesso negato

Il punteggio finale è influenzato anche da:

  • Ruolo: assegna bonus o penalità in base alla responsabilità (es. admin +10, dev/prod +5, guest -5)
  • Rete di provenienza: applica un moltiplicatore di fiducia (es. reti interne ×1.2, rete esterna ×0.9)
